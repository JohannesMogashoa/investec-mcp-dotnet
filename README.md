# Investec MCP

Investec MCP is a .NET 11 server for the planned read-only Investec banking integration. The baseline starts a local MCP server over standard input and output. It registers zero banking tools and requires no Investec credentials.

## Build and run

Install SDK 11.0.100 as pinned in [global.json](global.json). With the .NET Backports repository configured in Ubuntu 22.04 under WSL, run `sudo apt install dotnet-sdk-11.0`. The project also accepts an SDK installed in the repository’s `.dotnet/` directory.

Run these commands from the repository root.

```sh
dotnet restore
dotnet build -c Release
dotnet test
```

Configure your MCP client to launch the following command from the repository root after building.

```sh
dotnet src/InvestecMcp/bin/Release/net11.0/InvestecMcp.dll
```

For a project-local SDK, use `./.dotnet/dotnet` to launch the DLL. The server uses no HTTP listener. Standard output carries MCP messages and standard error carries logs. The xUnit project is ready for the protocol tests tracked in issue #02.

## Dependency updates

Projects enable NuGet lock files. Commit each project's `packages.lock.json` generated by a successful restore. Run `dotnet restore --locked-mode` to verify committed locks. When changing a package reference, run `dotnet restore --force-evaluate` and review the resulting lock file changes alongside the reference change.
